# 💖 Premium Matrix Love: Interactive Cyber-Romance Animation

Premium Matrix Love waa bog loogu talagalay soo bandhigista animation jaceyl oo casri ah (Digital Gift / Valentine's Webpage). Wuxuu isku dhex dhabbaa saamaynta caanka ah ee **Matrix Code Rain** iyo naqshadd dhalaysa wadne dynamic ah oo garaacaya, isagoo isticmaalaya HTML5 Canvas, Vanilla JavaScript, iyo Tailwind CSS.

---

## ✨ Awoodaha Boggan (Features)

* 🟥 **Rose Neon Matrix Rain:** Xarfo iyo calaamado jaceyl (01LOVE❤) oo si dynamic ah hoos ugu soo dhacaya iyagoo leh saameyn iftiimaya (Glow Effect).
* ⏳ **Immersive Countdown:** Marka bogga la furo, wuxuu ku bilaabanayaa tiris inta u dhaxaysa 3 ilaa 1 oo leh saameyn weynaan iyo libdhid ah (`fade-in`).
* 📜 **Dynamic Word Progression:** Tiri weyn ka dib, wuxuu soo bandhigayaa ereyo dareen xambaarsan oo is-bedbedelaya ("You", "Are", "My", "Everything").
* 💖 **Glassmorphic Beating Heart:** Dhamaadka animation-ka, waxaa soo baxaya wadne weyn oo leh neon glow, si dynamic ahna u garaacaya (pulsing/beating) oo ay ku qoran tahay fariin jaceyl.
* 📱 **Fluid Responsive Canvas:** Koodhka JavaScript wuxuu si otomaatig ah u cabbirayaa shaashadda (Resize Listener) si uu ugu shaqeeyo kombiyuutarka iyo moofaylkaba.

---

## 🛠️ Tiknoolajiyada la isticmaalay (Tech Stack)

* **HTML5 & Canvas API** - Loogu talagalay in lagu sawiro matrix-ka roobka ah si habsmooth ah.
* **Tailwind CSS** - Maamulka qaab-dhismeedka flexbox, midabada, iyo meelaynta walxaha.
* **Vanilla JavaScript** - Waa mishiinka rasmiga ah ee maamula saacadda tiriska, isku-beddelka ereyada, iyo xisaabinta dhibcaha roobka Matrix-ka.
* **Custom CSS Animations** - Loogu talagalay saameynta Glassmorphic iyo garaaca wadnaha (`@keyframes heartBeat`).
* **Google Fonts** - Font-ka rasmiga ah ee mustaqbalka ah (Sci-Fi) ee `Orbitron`.
